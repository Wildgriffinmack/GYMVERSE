Build a clickable mobile-first prototype for a fitness-only social media app called “GYMVERSE.”

App concept:
GYMVERSE is a gym-focused social platform for workout videos, gym motivation, transformation posts, progress tracking, and fitness challenges. It should feel like a mix of TikTok/Instagram Reels for gym content, Strava-style progress tracking, and a motivational fitness community. The goal of this prototype is to show the concept visually and allow users to click through the main screens. It does not need real authentication, real video uploading, or a backend yet. Use mock data and placeholder content.

Brand vibe:
The app should feel intense, modern, motivational, high-energy, and welcoming to both beginners and serious gym users. Since the name is GYMVERSE, the design can feel slightly futuristic, like a fitness universe/community built around progress, discipline, and transformation. It should not feel generic or corporate. It should have a dark-mode gym aesthetic.

Use this color palette:
- Background Black: #080A09
- Charcoal Card Gray: #151A17
- Electric Green: #39FF88
- Motivation Orange: #FF7A1A
- Pure White: #FFFFFF
- Steel Gray: #9CA3A0
- Deep Red Accent: #FF2E2E

Use the colors like this:
- Dark black/charcoal backgrounds
- White main text
- Steel gray secondary text
- Electric green for primary buttons, progress bars, active tabs, streaks, and completed challenges
- Orange for challenge buttons, motivational highlights, and calls to action
- Red only sparingly for alerts, report buttons, or intense PR badges

Build as a responsive mobile app prototype with a phone-like layout. Prioritize mobile screen size. The UI should look like an actual app demo.

Navigation:
Create a bottom navigation bar with:
- Home
- Explore
- Create
- Challenges
- Profile
Make the navigation functional between screens.

Prototype behavior:
- No real authentication required.
- No real backend required.
- Use mock data.
- Buttons should feel interactive.
- Tabs/categories can update visible mock content if simple to implement.
- Joining a challenge should update the button state.
- Posting should show a fake success message.
- The prototype should be clean, smooth, and easy to revise.

Design requirements:
- Mobile-first layout.
- Dark mode.
- Rounded cards.
- Bold headings.
- High contrast.
- Modern app feel.
- Use subtle gradients, shadows, and glowing green/orange accents.
- Make it feel energetic and fitness-focused, not generic.
- Add a slightly futuristic “fitness universe” feel to match the GYMVERSE name.
- Use icons where helpful.
- Make sure text is readable.

Important:
This is only the first prototype. Keep the code simple, organized, and easy to edit. Use reusable components for cards, buttons, navigation, category chips, post cards, challenge cards, and profile stats.
